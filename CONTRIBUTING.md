# Contributing to CRISPR

Bug reports, documentation improvements, and focused code contributions are welcome.

## Ask a question or report a problem

Check the [documentation](docs/README.md) and
[existing issues](https://github.com/ZuyiZhou/CRISPR/issues) first.
When opening an issue, include:

- The backbone and checkpoint directory you are using.
- Your Python, PyTorch, Transformers, CUDA, and GPU versions where relevant.
- The smallest command or code example that reproduces the problem.
- What you expected and the relevant error message.

Keep access tokens and private data out of logs and examples.

## Submit a change

Keep a pull request focused on one problem. Explain what changed, why it helps,
and how you verified it. For model changes, specify the backbone and checkpoint
used for validation. For documentation changes, check relative links and preview
the rendered Markdown.

Use the [appropriate installation instructions](README.md#quick-start) for the
part of the repository you are changing. Include the checks you ran in the pull
request; if a check needs unavailable hardware, state that clearly.
